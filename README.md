# AI-Powered Job Alert System

I built this project using **Claude Fable** to automate my job search and discover relevant opportunities across multiple job platforms.

I used Claude to generate the code while I defined the requirements, reviewed the implementations, and guided improvements throughout development.

## Features

- **Automated Job Search:** Collects job postings from multiple platforms using APIs.
- **AI-Powered Filtering:** Uses Claude's API to evaluate job descriptions and identify relevant opportunities.
- **Smart Matching:** Filters jobs based on location, experience level, and qualifications.
- **Duplicate Detection:** Tracks previously discovered jobs to avoid repeated alerts.
- **Email Notifications:** Automatically sends relevant opportunities to my inbox.
- **Scheduled Automation:** Uses GitHub Actions to run the system automatically.

## Tech Stack

**Python | Claude AI | Anthropic API | REST APIs | GitHub Actions | JSON**

## How It Works

`Job APIs → Data Collection → Job Filtering → Optional Claude AI Evaluation → Duplicate Detection → Email Alerts`
